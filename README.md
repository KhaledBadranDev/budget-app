# Budget App

A Python-based budget application that tracks spending across different categories and visualizes expenditure percentages.


## Description

This project implements a `Category` class to manage ledger transactions (deposits, withdrawals, transfers) and prints a formatted budget report. It also includes a `create_spend_chart` function to visualize spending distribution.


## Tech Stack

* Python 3


## Usage

Run the main script to see the output:

```bash
python main.py
```
